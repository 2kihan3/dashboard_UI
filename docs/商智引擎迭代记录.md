# 商智引擎迭代记录

适用范围：商智引擎的 Chatbot、经营看板、数据中心、Skill 市场和数据溯源。

## 维护规则

- 每次更新商智引擎功能后，在“迭代记录”顶部新增一条记录，按时间倒序维护。
- 每条记录仅描述迭代时间、功能点和业务逻辑；未上线能力须明确标注“筹备中”。
- 涉及页面字段、状态或权限规则变化时，需同步说明数据口径和限制条件。

## 当前功能基线

### Chatbot

- 支持查看历史会话、新建对话和展开全部会话记录。
- 支持输入问题、选择快捷 Skill、上传附件，并按时间范围和业务场景设置任务规则。
- 支持查看对话产出的日报等文件，并在右侧面板预览内容。

### 经营看板

- 已开放全局看板，可按时间周期、平台和店铺查看经营指标与趋势。
- 团队看板和个人看板当前为筹备中状态，暂不开放数据展示和自定义配置。

### 数据中心

#### 日报任务记录

- 顶部统计卡固定展示：日报任务总数、人工上传次数、未发布条数、失败次数、手动修改次数、豌豆消耗。
- 未发布条数 = 待发布条数 + 未发布条数；失败次数单独统计，不并入未发布条数。
- 手动修改次数只在人工复核保存了实际字段变更时累计；仅打开或保存未改动的复核不会增加次数。
- 支持按平台、店铺、任务日期、来源、归属人、审核人、任务结果和日报状态筛选任务。
- 支持查看任务结果、查看日志、发布日报、人工修改、重试、人工上传，以及单条或批量下载源表。
- 发布仅适用于已完成且已绑定的任务；发布后会写入日报数据。
- 人工复核保留原始任务结果和运行日志，发布时使用修正后的字段值。

#### 日报数据

- 仅展示已发布任务写入的日报数据。
- 支持按平台、店铺和业务日期筛选；查看明细会弹出当前筛选范围内的多日数据，支持手动填写和下载数据。
- 支持按平台下载日报模板。

### Skill 市场

- 按日报、费用、库存、营销、财务和数据接入等分类展示可复用技能。
- 支持从市场筛选技能，并在 Chatbot 中选择快捷 Skill 触发对应能力。

### 数据溯源

- 当前为筹备中状态。
- 规划支持“指标 → 字段 → 来源批次 → 审核记录”的全链路回查。

## 迭代记录

### 2026-08-24｜数据中心演示数据与分页补充

**功能点**

- 日报任务记录补充快手、爱库存、唯品会、好衣库、抖店和得物的多平台模拟任务，覆盖连续业务日期、自动任务、人工上传、已发布、待发布和失败等状态。
- 日报数据页中每个店铺均预置不少于 10 条已发布日报数据，便于验证日期筛选和多日明细查看。
- 日报任务记录和日报数据列表底部均增加分页器，每页展示 10 条记录。

**业务逻辑**

- 初始日报数据只由状态为“已发布”的任务生成，任务 ID、平台、店铺和业务日期与任务记录一一对应。
- 待发布和失败任务不会出现在日报数据中；在任务记录中发布后，仍按现有逻辑写入或覆盖同平台、同店铺、同业务日期的日报数据。
- 分页器以当前筛选结果为基础计算页数；变更筛选条件后自动回到第一页。

### 2026-08-14｜日报字段明细化与多日明细查看

**功能点**

- 日报任务结果预览和日报数据列表共用同一份平台字段配置。
- 快手展示技术服务费、分账佣金、其他费用、退货补运费、集运扣款（中转费）、消费者赔付和后台管理费；抖店展示运费险、消费者赔付、平台服务费、联盟佣金、评价有礼、其他扣款、千川推广和后台管理费。
- 爱库存展示营销活动优惠、交易手续费、运费险、消费者赔付、商家直客、超品扣点费、其他扣费和后台管理费；唯品会展示平台成交 GMV、活动折扣；好衣库展示平台成交 GMV、技术运营服务费、快递信息服务费。
- 日报数据列表保留日期筛选器右侧的“查看明细”按钮，点击后在弹窗中展示当前筛选范围内的多日数据。

**业务逻辑**

- 平台费用、推广费用和后台管理费均按实际字段保存和展示，不再把括号中的费用项汇总为单一“平台管理费”。
- 人工复核修改后的字段会覆盖对应明细字段，发布日报后写入日报数据。
- 多日明细弹窗沿用当前的平台、店铺和业务日期筛选条件；按日期倒序展示全部已发布记录。当前筛选结果为空时，按钮不可操作。

### 2026-08-13｜日报任务人工上传资料清单

**功能点**

- 人工上传弹窗改为绑定当前日报任务，不再以单文件方式另建人工上传任务。
- 人工上传保留“下载模板 → 上传资料”两步流程；下载清单与上传资料清单一一对应，模板会带入当前任务的平台、店铺和业务日期。
- 弹窗固定展示任务编号、平台、店铺和业务日期，并按平台展示必传资料清单及完成进度。
- 快手需上传账单明细表和结算明细表；好衣库、抖店、爱库存各需上传一份对应日报资料。
- 唯品会需上传产品上新统计表和“商品明细-货号力度-跨天不去重”资料；商品明细支持一次添加多份文件。

**业务逻辑**

- 所有资料均绑定当前任务的业务日期，前端提示文件日期、表头和格式将在提交后校验。
- 必传资料未齐全时，“提交资料并校验”不可操作；每类资料可替换，唯品会商品明细可追加或逐份移除。
- 提交后，文件名、资料类别和任务编号写入当前任务记录；不会新增另一条日报任务。
- 唯品会产品上新统计表保留 D 列品牌款号解析，解析失败时阻止提交。

### 2026-08-12｜经营看板指标卡收拢至统计图标题

**功能点**

- 经营看板新增起止日期时间筛选器，并保留年、月、周、日四个固定快捷维度。
- 移除全局经营看板顶部的 GMV、平台费用合计、管理费用合计指标卡。
- 将对应的周期汇总值放入各统计图标题栏右侧，并提高标题区域高度。
- 唯品会的活动折扣、好衣库的技术运营服务费和快递信息服务费在日维度改为店铺数据卡展示。

**业务逻辑**

- 选择完整起止日期后，日期范围覆盖当前固定维度；点击年、月、周、日或“清除”后恢复对应固定维度。
- 时间筛选与平台、店铺筛选同时生效，统计图和标题汇总值使用同一范围取数。
- 标题右侧的汇总值复用原指标卡的计算口径，按当前选择的周期、平台和店铺同步刷新。
- 日维度展示“当日汇总”；周、月、年维度展示“周期汇总”。
- 日维度下，上述指标按当前平台的店铺集合生成数据卡；选择店铺后仅保留对应店铺的卡片。
- 快手和爱库存的管理费用使用虚拟费用明细：运营人力费用、系统服务费、办公与行政费用；图表按三项费用叠加展示，总额为三项之和。
- 日维度选择具体店铺后，快手和爱库存的管理费用改为费用构成饼图；未选择店铺时继续展示平台级叠加柱。

### 2026-08-12｜日报任务记录统计卡更新

**功能点**

- 将日报任务记录顶部统计区调整为六张卡：日报任务总数、人工上传次数、未发布条数、失败次数、手动修改次数、豌豆消耗。
- 保留原有“人工上传次数”统计卡，并新增未发布条数和手动修改次数。
- 补充人工修改任务的示例数据，用于展示不同状态下的统计结果。

**业务逻辑**

- 人工上传次数按任务来源为“人工上传”或“人工上传文件”的任务累计。
- 未发布条数合并统计“待发布”和“未发布”状态。
- 手动修改次数按每次保存且存在字段变更的人工复核累计，允许同一任务多次修改。
- 六张卡在宽屏展示为六列，在中小屏自动调整为三列、两列或单列。
