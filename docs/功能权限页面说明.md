# 功能权限页面说明

适用位置：`Admin > 权限管理 > 功能权限`

## 资源结构

功能权限以树形方式管理平台资源。功能类型决定其下级层级，共有两种结构：

```text
模块
├─ 功能（页面类型）
│  └─ 按钮
└─ 功能（按钮类型）
   └─ 页面
      └─ 按钮
```

| 层级 | 所属父级 | 页面中的作用 |
| --- | --- | --- |
| 模块 | 系统根目录 | 管理一个业务板块，例如电商生图、AI 开品。 |
| 功能 | 模块 | 管理板块内的能力入口；新增时可选择“页面”或“按钮”类型。 |
| 页面 | 按钮类型功能 | 管理具体可访问页面及其页面路由。 |
| 按钮 | 页面或页面类型功能 | 管理页面内的操作权限，例如新增、编辑、删除、导出、审核。 |

## 树形页面操作

| 资源层级 | 可用操作 | 说明 |
| --- | --- | --- |
| 模块 | 新增模块、编辑、启用/停用、删除、新增功能 | 模块是顶层资源，可展开查看下属功能。 |
| 功能 | 编辑；页面类型可新增按钮；按钮类型可展开/收起并新增页面 | 页面类型是可直达页面；按钮类型是下属页面的展开/收起节点。 |
| 页面 | 展开/收起、编辑、新增按钮 | 页面下可继续维护具体操作按钮。 |
| 按钮 | 编辑 | 按钮的完整权限定义在新增时填写。 |

资源树中的同级节点按“排序”值从小到大展示。修改排序后，同级节点会自动重新排列。

## 新增模块

点击页面右上角“新增模块”，填写以下字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 模块的展示名称。 |
| 标识 | 模块的唯一业务标识。 |
| 排序 | 控制模块在顶层树中的展示顺序。 |
| 状态 | 选择启用或停用。 |
| 页面路由 | 模块入口路径；未填写时按标识生成默认路径。 |

## 新增功能

在模块行点击“新增功能”后，先选择功能类型。

| 功能类型 | 需填写字段 | 规则 |
| --- | --- | --- |
| 页面 | 名称、标识、功能类型、排序、状态、页面路由 | 功能本身是可直达页面，不展示下属页面的展开入口，但可直接新增页面按钮。 |
| 按钮 | 名称、标识、功能类型、排序、状态 | 不显示页面路由；功能本身是展开/收起下属页面的交互节点。 |

页面类型功能的页面路由为空时，系统按功能标识生成默认路径。

## 新增页面

在功能行点击“新增页面”，填写以下字段：

| 字段 | 说明 |
| --- | --- |
| 名称 | 页面的展示名称。 |
| 标识 | 页面的唯一业务标识。 |
| 排序 | 控制页面在当前功能下的展示顺序。 |
| 状态 | 选择启用或停用。 |
| 页面路由 | 页面访问路径；未填写时按标识生成默认路径。 |

## 新增按钮

在页面行，或页面类型功能行，点击“新增按钮”。除基础字段外，还需配置具体权限定义。

| 字段 | 说明 |
| --- | --- |
| 名称、标识、排序、状态 | 按钮的基础管理字段。 |
| 所属父级 | 当前页面或页面类型功能名称，由系统自动带入，只读展示。 |
| 说明 | 记录按钮的业务用途，便于后续维护。 |
| 操作类型 | 可选新增、编辑、删除、导出、审核、发布或自定义。 |
| 权限点标识 | 用于前端或后端权限校验，例如 `ecom.task.create`。 |
| 请求方法 | 可选 `GET`、`POST`、`PUT`、`PATCH`、`DELETE`。 |
| 关联接口 | 按钮对应的接口路径，例如 `/api/ecom/tasks`。 |

## 编辑与状态管理

模块、功能、页面和按钮均可通过编辑入口修改名称、标识、排序和状态。按钮的说明、操作类型、权限点标识、请求方法和关联接口仅在新增时填写，编辑时仅调整基础字段。

模块、功能、页面还可修改页面路由。模块行额外提供独立的启用/停用快捷操作；功能、页面和按钮的状态在编辑弹窗内调整。

## 技术实现约束

三层和四层资源可以同时存在，不需要按层级拆成固定的多张数据表。建议以统一资源树保存，并通过节点类型和父子关系约束层级。

| 字段 | 说明 |
| --- | --- |
| `id` | 资源唯一 ID。 |
| `parent_id` | 父资源 ID；模块的父级为空。 |
| `node_type` | 资源类型：`module`、`function`、`page`、`button`。 |
| `function_mode` | 仅功能节点使用：`page` 表示可直接访问的页面，`group` 表示仅用于展开下属页面的分组。 |
| `route` | 模块、页面类型功能和页面可配置；分组类型功能与按钮不配置路由。 |
| `permission_code` | 用于前端或后端校验的权限标识。 |
| `sort`、`status` | 分别控制同级排序和启用状态。 |

资源树的父子关系应校验如下：

```text
模块 → 功能（页面类型）→ 按钮
模块 → 功能（分组类型）→ 页面 → 按钮
```

页面类型功能只能新增按钮；分组类型功能只能新增页面；页面只能新增按钮；按钮始终为叶子节点，不允许继续新增下级资源。

为避免与实际操作按钮混淆，功能节点的“按钮类型”建议在产品界面中命名为“分组类型”。它只用于展开或收起下属页面，不代表一个可执行的按钮权限。
