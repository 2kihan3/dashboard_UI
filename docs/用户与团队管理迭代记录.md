# 用户与团队管理迭代记录

## 2026-08-13｜账号创建、团队成员与小组归属

### 平台用户管理

- 用户管理仅保留“超管”和“系统管理员”两个创建入口。
- 超管创建账号时，可选择是否设为系统管理员；系统管理员创建账号时不提供该选项。
- 两类创建入口均可选择账号是否直接归属商户团队。
- 选择归属团队后，显示商户团队选择和“商户管理员 / 普通成员”组织角色；不归属团队时，仅创建全局账号。

### 商户团队成员管理

- 商户管理员不使用平台用户管理，在团队管理中创建成员或邀请已有账号。
- 创建成员需填写完整账号信息，并强制选择业务角色。
- 创建时可独立选择是否分配商户管理员身份，以及是否分配到小组。
- 分配到小组后，需选择小组名称和小组角色（小组长或组员）；当前团队没有小组时，页面提示先前往小组管理创建。
- 邀请已有账号仅支持完整邮箱精确匹配。匹配成功后可选择业务角色，以及普通成员或商户管理员身份。
- 已在团队内的账号再次被邀请时，更新其业务角色和组织身份，不重复创建成员记录。

### 小组长管理范围

- 小组长仅查看和操作所属小组的成员。
- 小组长可创建账号或邀请团队内、全局账号；创建和邀请成功后，账号强制归属当前小组，并固定为组员。
- 小组长创建和邀请时必须选择业务角色，不可为成员额外分配商户管理员身份。

### 小组成员列表与成员管理

- 小组管理列表支持展开查看组内成员，成员明细展示业务角色、小组身份、账号状态、个人豌豆余额及成员操作。
- 每个小组增加“成员管理”入口，可从当前团队成员中加入成员，并指定为组员或小组长；指定新组长时，原组长自动调整为组员。
- 成员在加入新小组时会同步转移小组归属；若其原本为原小组长，原小组将取消该组长标记。
- 成员管理弹窗支持完整邮箱精确匹配邀请全局账号。通过该入口邀请的账号会直接加入当前小组并默认成为组员。
- 支持在弹窗或展开列表中将成员移出小组；移出小组只解除小组关系，不删除团队成员账号。

### 前端状态说明

- 当前实现使用前端静态数据模拟全局账号池、团队成员关系和小组归属。
- 后端接入时应分别持久化全局账号、团队成员关系、小组成员关系，并以完整邮箱作为邀请查找条件。
